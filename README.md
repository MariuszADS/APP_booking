# Booking app

## Tech Stack
### Client
* React
* TypeScript 
* Vite
* React-router

### Server
* Node
* Prisma
* PostgreSQL 

# Description
- Backend for a booking application with JWT authentication.Supports login, registration, and booking operations.Intended to run locally for development.

## Run locally
* 1.`npm install`
* 2. to run client: `npm run dev`
  3. to run server: `npm start`

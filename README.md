# Booking app

## Tech Stack
### Client
* React
* TypeScript 
* Vite
* React-router

### Server
* Node
* Prisma
* PostgreSQL 

# Description
- Full-stack booking application with both frontend and backend.
Backend uses Node.js, Express, and JWT authentication.
Includes user registration, login, and booking management.

## Run locally
* `npm install`
* run client: `npm run dev`
* run server: `npm start`
